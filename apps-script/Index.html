使用流程

老師每月進入「月報填報」完成資料，送出後由主管於「月報後台」查看、審核與匯出正式檔案。

填寫提醒

出勤與教學紀錄會參考上一期內容；若上一期沒有資料，系統會放入 0 次 / 0 小時範例，方便直接修改或刪除。
